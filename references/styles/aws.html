AWS reference-architecture style

Match the look of aws.amazon.com/architecture/reference-architecture-diagrams. White page, AWS Squid-Ink outlines for the Region, green for VPCs, dashed teal for Availability Zones, square service badges colored by category, and orange-amber A/B/C/D step markers. Use the --c-* CSS variables — never hardcode service colors. The icon symbols below are intentionally abstract: the colored badge encodes the category and the label encodes the service (e.g. ico-aws-compute + label "Lambda" or "EC2" or "Fargate").

Container conventions

AWS Region — solid #232F3E 1.5px, label uppercase 13px top-left.
VPC — solid green #7AA116 1.5px, "VPC" label + CIDR top-left.
Availability Zone — dashed teal #00A4A6 1.5px (stroke-dasharray="6,4"), uppercase label.
Subnet (public) — green dashed; (private) — teal dashed.
Account / Auto Scaling Group — orange dashed #ED7100.
Corporate data center — solid gray #5b6770 with a building glyph in the corner.

Step markers

Orange-amber #FF9900 rounded square (18×18, rx=3) with a single bold black-ish letter or number inside. Place the marker at the midpoint of each labeled segment. Numbers 1, 2, 3 … for the runtime/request path; letters A, B, C … for ingestion or any secondary path.
