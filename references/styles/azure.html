Microsoft Azure architecture style

Match the look of learn.microsoft.com/en-us/azure/architecture/browse. White page, Segoe UI, Azure-blue solid borders for Subscriptions and VNets, dashed Azure-blue for Resource Groups, and a Fluent multicolor service icon palette anchored on Azure blue (#0078D4). Connectors are neutral gray #605E5C; private endpoints / VNet integration use Azure-blue dashed.

Container conventions

Subscription — solid Azure-blue #0078D4 1.5px, low-saturation blue chip top-left (#DEECF9) with dark-blue label.
Resource Group — dashed Azure-blue 1.5px (stroke-dasharray="6,4"), same chip style for the label.
VNet — solid darker blue #005A9E 1.5px.
Subnet — solid cyan #50E6FF 1px.
Sharp/near-sharp corners (rx 2) — Azure diagrams favor rectilinear edges over rounded.

Icon conventions

Rectangular badge (rx=4) filled with the category color and a white glyph. The Fluent palette is more saturated than the AWS or GCP palettes — use the variables, don't hand-pick. Title 12px Segoe UI bold, subtitle 10.5px muted gray.

Connector conventions

Solid neutral gray #605E5C 1.5px for normal flows; dashed Azure-blue #0078D4 for VNet integration / private endpoints. Step markers are 9px Azure-blue circles with white bold numbers (request path) or letters (ingestion / private path).
