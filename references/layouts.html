Architecture Diagram Layouts Reference

Swimlane Flowchart

Parallel process flows with separate lanes for different actors, teams, or systems. Arrows show handoffs and dependencies.

Canvas Size: 1100×720
Lane Height: 140–180px
Node Spacing: 80–100px (horizontal)
Best for:
  • Multi-actor workflows (user → admin → system)
  • Process flows with handoffs
  • Team responsibilities and dependencies
Base node: (x, y) in lane | Lane spacing: y += 65
Cloud Architecture Diagram

Microservices, cloud services, and distributed systems with connectivity between services.

Canvas Size: 1000×700
Node Size: 140×70 to 160×80
Grid Spacing: 250×150px
Best for:
  • Microservices architectures
  • Cloud infrastructure (AWS, GCP, Azure)
  • Service-to-service communication
Nodes arranged in grid | Arrows connect services bidirectionally
Sequence Diagram

Time-ordered interactions between actors or services. Vertical timelines with horizontal interaction arrows.

Canvas Size: 1200×900
Actor Spacing: 200–250px
Message Height: 60–80px
Best for:
  • Request/response flows
  • Interaction timing diagrams
  • Message passing between actors
Actors at top | Lifelines drop vertically | Messages move horizontally
Data Flow Diagram (DFD)

Data movement and transformation across processes, data stores, and entities. Shows input → processing → output.

Canvas Size: 1000×700
Node Types: Circle (process), Rectangle (store)
Data Labels: On arrows
Best for:
  • ETL pipelines (Extract → Transform → Load)
  • Data transformation flows
  • Information system design
Processes: circles | Data stores: rectangles | Label arrows with data type
Entity Relationship Diagram (ERD)

Database schema with entities, attributes, and relationships. Shows cardinality and key constraints.

Canvas Size: 1000×700
Entity Box: 160×80
Cardinality: 1:1, 1:N, M:N symbols
Best for:
  • Database schema design
  • Table relationships and constraints
  • Normalized data models
Entities in rectangles | Primary keys (PK) and foreign keys (FK) labelled | Cardinality on arrows
Top-Down Flowchart

Hierarchical step-by-step flows. Top node represents the start or main process, branching downward.

Canvas Size: 800×900
Level Spacing: 150–180px (vertical)
Node Centering: Automatic
Best for:
  • Decision trees
  • Algorithm flowcharts
  • Hierarchical process breakdowns
Root node at top | Branch connectors | Auto-center alignment
